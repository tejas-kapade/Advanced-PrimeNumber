# PrimeNumber
Prime Number Detection ( Version 3.3 )

This project is Based on GUI (tkinter library)

Features:
1. Check provided number is prime or not.
2. Get list of prime numbers as many we want.
3. Export generated prime number data in PDF or CSV format.
4. Store all exported data in reports folder.
5. Store all logs of generated prime numbers data in logs folder.
6. Option to view or delete exported data pdf or csv.
7. Option to view logs.
8. Option to view list of generated prime numbers.
9. Option to delete all logs and all exported pdf and csv data using admin password. ( Default password: Prime@123 )

Requirements (Libraries to install using pip):
1. reportlab
2. tkinter
3. time, datetime
4. tqdm
